# Customer_Behavior_Analysis
# 🛍️ Customer Shopping Behavior Analysis

## Overview

An end-to-end **Data Analytics project** analyzing customer shopping behavior using Python, SQL, PostgreSQL, and Power BI.

The project covers **data cleaning, exploratory data analysis, SQL analysis, dashboard development, and business insights**.

---

## Dataset

The dataset contains **3,900 customer records and 18 attributes**, including customer demographics, purchases, products, ratings, discounts, subscriptions, shipping, and payment information.

---

* **Python** – Data cleaning and EDA
* **Pandas** – Data manipulation
* **PostgreSQL** – SQL analysis
* **Power BI** – Dashboard and visualization

## Data Analysis

### Python

The dataset was loaded and analyzed using Pandas. The analysis included:

* Data exploration
* Missing value handling
* Data type checking
* Column standardization
* Feature engineering
* Customer age grouping

Missing review ratings were handled using the median rating of the corresponding category.

---

## SQL Analysis

The cleaned data was loaded into PostgreSQL and analyzed using SQL.

Key analysis included:

* Revenue by gender
* Discount and spending behavior
* Top-rated products
* Standard vs. Express shipping spending
* Subscriber vs. non-subscriber spending
* Product discount rates
* New, Returning, and Loyal customer segments
* Top products within each category
* Repeat buyers and subscription behavior
* Revenue by age group
